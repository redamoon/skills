# AI偏愛比喩動詞カタログ

抽象的な事象やシステム・データの変化を、安易な比喩動詞で言い換える手癖のカタログ。`forbidden-patterns.md` が語彙の空疎さを扱うのに対し、ここは動詞の比喩的用法──特に無生物（システム・データ・前提・文化など）を主語にしたときに不自然になる動詞──に絞る。出典は [yomiyasu](https://github.com/nanaism/yomiyasu) の規範（MIT）。

## 見分け方

同じ動詞でも、主語が人間や身体・物理的な物体なら比喩ではなく正当な用法になる。「時計が壊れる」「お腹を壊す」はそのまま残してよい。「データが壊れる」「設計が壊れる」のように、抽象的な対象に対して使われているときだけがAI偏愛比喩動詞の対象になる。

もう一つの軸は、慣用句として日本語にすでに定着しているかどうか。「骨が折れる」「手を焼く」「目から鱗が落ちる」「首を長くして待つ」は、AIが広まる前の人の文章でもふつうに見かける慣用句であり、比喩として扱わずそのまま残してよい。業務仕様の中でも、意味を取り違えるおそれがなければ残す。迷ったら、その言い方をAIが広まる前の文章で見かけるかどうかを基準にする。

## カタログ

| 比喩動詞 | AI特有の用例 | 自然な表現への修正方針 |
|---|---|---|
| 効く / 効いてくる | 「地味に効きます」「〜が効いてくる」 | 「目立たないながらも役に立つ」「じわじわ助けになる」（「地味に」の含みは残す） |
| 壊れる（抽象主語） | 「データが静かに壊れる」「設計が壊れる」 | 「整合性が失われる」「不整合が起きる」「破綻する」のように客観的・技術的な表現に具体化する（言い切りの強さは弱めない）。時計・機械・身体など物理的対象の「壊れる」はそのまま維持する |
| 倒す | 「〜側に倒す」「残さない側に倒す」 | 「〜を優先する」「〜の扱いに統一する」「除外する」 |
| 溶かす | 「時間を溶かしました」 | 「思わず多くの時間がかかってしまった」「時間を費やしてしまった」（無駄にした・かかってしまった後悔の含みは残す） |
| 潰す | 「1つずつ潰していく」 | 「1つずつ直す」「消す」「解決する」 |
| 踏み込む | 「〜まで踏み込んで」 | 「詳しく調べる」「掘り下げる」 |
| 引き返す | 「動かしながら引き返す」 | 「元の状態に戻す」 |
| 添える | 「経路が代わりに添える」 | 「渡す」「つける」 |
| 収斂する | 「その価格帯に収斂した」 | 「落ち着いた」「決まった」 |
| 沈黙する / 黙って | 「静かに沈黙する」「黙って無視される」「黙って捨てられる」 | 「何も通知が出ないまま終了する」「気づかないうちに無視される」「知らないうちに破棄される」（原因を勝手に狭めない。「エラーを出さずに」「通知なく」のように仕組みの話にするのは、元の文や前後から明らかなときだけ） |

## 英語直訳由来の構文

| 英語の原表現 | AIの直訳日本語 | 自然な日本語 |
|---|---|---|
| silently fail / ignored | 「静かに壊れる」「黙って無視される」 | 「気づかないうちにデータの整合性が失われる」「知らないうちに無視される」 |
| the moment ... | 「〜した瞬間」「〜した瞬間に」 | 「〜するとすぐに」「〜した時点で」 |
| point to / suggest | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜と考えられる」「〜を意味する」 |
| load-bearing | 「耐力のある」「構造を支える」 | 「不可欠な」「根幹となる」「外せない」 |

これらは `references/translationese.md` の「無生物主語 + 他動詞」節と同根の現象で、述語が比喩動詞のときに特に見分けにくい。主語が無生物で述語がこのカタログの動詞に当たるときは、二重にチェックする。

## 意味保持の原則

比喩を解体するときも、比喩が運んでいた含み（気持ちや評価の向き）は残す。「うっかり」の不注意、「ようやく」の待ちくたびれた感じ、「〜てしまった」の後悔、「地味に」の目立たないけれど確かにある感じ、といった含みを、別のふだんの言葉で補って言い表す。動詞を言い換えるだけで含みごと削ぎ落とすと、文の言い切りの強さや評価のニュアンスまで変わってしまう。
